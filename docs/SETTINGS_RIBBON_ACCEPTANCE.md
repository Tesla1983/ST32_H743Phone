## 2. 实现要点

### 2.1 卡片本体

`third_party/YMGUI/project_Demo/phone_shell/apps/settings.c`

- 卡片位置：内容坐标 `y=269`、高 `50`、白底，宽 `284`
- 标题 `T("半透明")` / 副标题 `T("透出")` 或 `T("实色")`，文案随当前效果自动跟随
- 开关：`YMGUI_Creat_Switch_Creat(rib, 218, 11, 48, 27)`
- **开关语义取反**（重要，改动时别弄反）：开关名就是功能名"半透明"，所以
  - UI 初态 = `PhoneHost_GetRibbonTranslucent() ? 0 : 1`
  - 回调里 = `PhoneHost_SetRibbonTranslucent(on ? 0 : 1)`

### 2.2 滚动容器

七张卡片按 50 px 等分排到 `y=491`，超出可视区 60 px。改为可上下滚动：

| 项 | 内容 y | 高 |
| --- | --- | --- |
| 无线网络 | 65 | 50 |
| 海蓝色壁纸 | 133 | 50 |
| 界面语言 | 201 | 50 |
| **半透明效果（新增）** | **269** | **50** |
| 预览亮度 | 329 | 62 |
| 设备名输入 | 407 | 28 |
| 关机按钮 | 451 | 40 |

- 视口几何：`SCROLL_HEAD_H = 56`（让出头部），`SCROLL_VIEW_H = 412 - 56 = 356`
- 内容总高 `content_h = 491` ⇒ **clamp 上限 = 491 - 356 = 135**
- 滚动条与视口**平级**（建成视口子对象会跟着 `scroll_y` 滑走，失去意义）
- 底部三项（329 / 407 / 451）在 `scroll_y=0` 时落在视口外 ⇒ **任何脚本/自检要点关机按钮，必须先滚到底**

### 2.3 持久化

`src/app_config.c` — 与「界面语言」共用同一个结构体与同一个扇区。

- 扇区 **240 = `0x000F0000`**，magic `"YCON" 0x59434F4E` + CRC32 双校验
- 选址在字库末尾 `0xEFC00` 之后、擦写回环 `0xFE000` 之前的空隙
- 低频改动 + `qspi_write` 自带"内容未变跳过擦除" ⇒ 闪存寿命等于无限

## 4. 验收过程中修掉的缺陷

| # | 缺陷 | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | 收键盘动作把用户踢出设置页 | 用了导航栏 **home 键**，它走 `on_home` 直接回桌面 | 改用键盘自己的收起键 `(287,267)`；脚本侧更稳的是返回键 `(64,464)`（`on_back` 里 `PhoneIME_Hide()` 优先级最高） |
| 2 | 拖动会误触输入框、键盘突然弹出 | 引擎在 `Pressed` 时给命中的可聚焦对象置焦点，设备名输入框就在滚动区里 | `scroll_drag()` 在**首次**判定为滚动时 `YMGUI_SetFocus(c, NULL)`（只做一次，反复做会打断真实编辑） |
| 3 | 设置页标题被完全遮住 | 滚动视口 `bg_color` 不透明 + 开 `ClipChildren`，且**建在头部之后** ⇒ 后建的画在上面 | 视口从 `y=SCROLL_HEAD_H=56` 起、高 356 |
| 4 | 关机按钮坐标点空 | 坐标在"布局变化时算一次"，而 `app_page` 自己停在 `y=480`（`on_recent` 会把它推回屏幕下方） | 改由固件 `app_tick` **每帧**用 `YMGUI_Obj_GetAbsArea` 现算，脚本只读 |
| 5 | 诊断量与画面不一致 | `g_diag_power_dialog` 在 setter 里"顺手增量同步"，被 `-O2` 内联后与真实状态脱节（`state=0x04` 但诊断量报 1，稳定复现 3 次） | 全部改成 `advance()` 里**每帧现算**，不维护镜像 |
| 6 | 抓屏图两次逐字节相同 | `g_frame_mirror` 只在 `phone_flush` 被调时拷；画面静止时 `YMGUI_Refresh` 因脏区为空直接 return ⇒ 镜像停在旧帧 | 新增 `g_force_redraw`（`src/main.c`）：写 1 → 下一拍强制整屏标脏并重绘，自动清 0 |
| 7 | 验收脚本读状态量过早 | `bdtap` 注入是**异步**的（写 seq → 下一次 `BoardTick` 才消费） | 新增 `settle()`，读状态前必调 |
| 8 | 开关点空（误报"开关没翻转"） | `wait_diag()` 调在 `open_settings()` **之前**，读到 `app_page` 还在 y=480 时的旧坐标 | 顺序反过来 |

## 5. 验收期新发现、尚未修完的缺陷（**已如实记录，未擅自改动**）

### 5.1 输入框被键盘遮挡时的避让逻辑在滚动容器里错位

`phone_ime.c` 的 `PhoneIME_Show()` 有一段"把被遮挡输入框上移/压扁"的避让：

```c
YMGUI_Obj_GetAbsArea(active->obj, &abs);      /* 绝对坐标（含父链 scroll_y） */
...
active->obj->area.y -= abs.y - (KEYBOARD_Y - 44);   /* ← 局部坐标 -= 绝对差值 */
active->obj->area.h  = KEYBOARD_Y - 6 - abs.y;
```

**坐标系混用**：前者绝对、后者局部。在无滚动的定长页面里两者恰好一致、凑巧能用；
一旦父对象是滚动容器（`scroll_y ≠ 0`），就会把控件挪到**视口外面**。

**实测症状**（板级抓屏 `build/ime_after.png` + 像素扫描）：
- 输入框被挪到视口顶边以上，压在标题上；`abs y=80..88` 有 79~82 个非背景像素（残字），`y=90/91` 干净 ⇒ 溢出点正好在视口顶 92 之上
- 更早还观察到输入框直接压在「界面语言」卡片上，两行文字叠成乱码

**已实施的对冲**（不依赖被 IME 改坏的坐标）：
- `settings.c` 新增 `scroll_apply_ime()`：键盘弹起时把**视口高度缩到键盘上沿**，
  并把焦点输入框滚进视野（实测 `scroll_y` 135 → 307，= `407+28-128`）
- `phone_ime.c` 新增 `PhoneIME_RegisterSelfAvoiding()`：**注册制**——
  容器自己管避让就登记，未注册的容器行为与改动前**完全一致**
  （曾想按"祖先有 ClipChildren 且 scroll_y≥0"判定，但本工程有 6 处开 ClipChildren，
  大部分是普通裁剪容器、scroll_y 恒 0，纯结构判据会误伤定长页面）

**未完成部分**：视口顶 y=80..88 的溢出**仍存在**（`scroll_y=307` 时）。
已排除 IME 挪控件（挪控件会带白底卡片，实测溢出的是灰色文字像素、无卡片底色）
与引擎裁剪缺陷（`YMGUI_Obj_GetAbsArea` 已正确减父 scroll，见 `YMGUI_Obj.c:278-298`）。
**下一步定位方向**：怀疑是渲染 band 划分与 `scroll_y` 的交互，需在
`YMGUI_Invalidate.c:250` 的 `GY_Rect_Intersect(&newclip, &abs, &s->clip)` 处打点。

### 5.2 其他遗留（与本次需求无关，早前已知）

- `selftest()` 仍是 SDL 桌面版入口，板上无触发路径
- heap1 峰值 97%（剩约 7 KB）⇒ 词组词典/英文词典必须保持关闭，
  代价是中文候选只能按单字频率排序（`zhongguo` 首位不是"中国"）—— 已知取舍，不是 bug
- TF 卡 L2/L3 尚未开工，见 `docs/TF_CARD_CACHE_ROADMAP.md`

## 8. 写给下一个改这段代码的人

1. **坐标一律读固件诊断量**（`g_diag_ribbon_sw_x/_y`、`g_diag_power_btn_x/_y`、
   `g_diag_scroll_y/_max/_content`），脚本不要按算式推 —— 本项目因此踩了 3 次。
2. **诊断量必须每帧现算**，绝不在"状态变化处"增量同步（`-O2` 内联会让编译器看不到
   `volatile` 只有 SWD 在读）。且坐标类要用 `YMGUI_Obj_GetAbsArea`，
   因为 `app_page` 会停在 `y=480`。
3. **点关机按钮前必须先滚到底**（`scroll_y=0` 时它在屏幕之外）。
4. **`bdtap` 注入是异步的**：读状态前调 `settle()`，别靠 `drag` 的 `wait` 顺带等。
5. **后建的画在上面**：不透明 + ClipChildren 的容器会盖住建在它之前的兄弟对象
   （标题被遮就是这么来的）。
6. **收键盘用返回键 `(64,464)` 或键盘自己的收起键 `(287,267)`**，
   **绝不要用 home 键 `(160,464)`** —— 它会直接退出到桌面。
7. 改设置页布局**必须同步** `phone_shell/phone_selftest.inc` 里的坐标断言。
